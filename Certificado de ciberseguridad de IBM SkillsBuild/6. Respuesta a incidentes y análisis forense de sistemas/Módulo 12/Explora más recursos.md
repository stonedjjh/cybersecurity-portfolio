# ¡Explora más recursos!

Para explorar los conceptos cubiertos en este módulo con más profundidad, consulta estos recursos:

- [What Is Digital Forensics?](https://www.eccouncil.org/cybersecurity/what-is-digital-forensics/) Este sitio web del EC-Council proporciona un resumen detallado del campo de la ciencia forense digital, incluida su historia, requisitos laborales y desafíos.

- [Digital and Multimedia Evidence](https://www.nist.gov/spo/forensic-science-program/digital-and-multimedia-evidence). Este sitio web proporciona enlaces a productos y servicios forenses digitales útiles del NIST, como un catálogo de herramientas y técnicas forenses digitales.

- [Chances for data recovery](https://www.ufsexplorer.com/articles/chances-for-data-recovery/). Este sitio web resume varias causas de pérdida de datos y cómo cada una afecta las posibilidades de una recuperación de datos exitosa.

- [The Anatomy of an Att&ck](https://youtu.be/2icKi2q6NS4). En este video, Jeff Crume, ingeniero distinguido de IBM y maestro inventor, explica cómo los atacantes irrumpen en los sistemas, lo cual es un conocimiento útil para identificar y recopilar datos forenses digitales.

- [Kali Linux](https://www.kali.org/). El sitio web oficial de Kali Linux ofrece numerosos recursos sobre esta distribución de Linux, como descargas, documentación, foros y cursos.
