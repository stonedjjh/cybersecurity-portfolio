# Glosario de Términos de Seguridad de Red

| Término                                           | Definición                                                                                                                                                                                                             |
| :------------------------------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Access Control List (ACL)**                     | Conjunto de reglas utilizadas para determinar si una dirección IP de origen o un servicio tiene permitido el ingreso a la red.                                                                                         |
| **Application Files**                             | Archivos ejecutables y recursos asociados necesarios para ejecutar aplicaciones, garantizando operaciones de software correctas y seguras.                                                                             |
| **Application-Level Firewalls**                   | Firewalls que operan en la capa de aplicación del modelo OSI e inspeccionan la carga útil de los paquetes para proporcionar un control granular basado en datos específicos de la aplicación.                          |
| **Artificial Intelligence (AI)**                  | Uso de máquinas y algoritmos para simular la inteligencia humana, mejorando la detección de amenazas mediante el análisis de patrones y anomalías en los datos de seguridad.                                           |
| **Automated Remediation**                         | El proceso de abordar automáticamente los problemas de incumplimiento y restaurar el acceso a la red para usuarios legítimos.                                                                                          |
| **Behavioral Analysis**                           | Supervisa los comportamientos de los terminales y de la red para detectar desviaciones de la actividad regular, ayudando a identificar amenazas de día cero y amenazas persistentes avanzadas.                         |
| **Class of Service (CoS)**                        | Método utilizado para priorizar el tráfico de red mediante su marcado, mejorando la gestión de la calidad y el rendimiento de la red.                                                                                  |
| **Cloud Security**                                | Medidas y tecnologías utilizadas para proteger datos y aplicaciones almacenados en entornos de nube, integradas en XDR para una seguridad integral.                                                                    |
| **Data Loss Prevention (DLP)**                    | Conjunto de herramientas y procesos utilizados para monitorear, detectar y bloquear transferencias de datos no autorizadas, protegiendo la información sensible de amenazas internas y externas.                       |
| **Destination IP Address**                        | La dirección IP del dispositivo o servidor de destino al que se pretende que llegue un paquete de red.                                                                                                                 |
| **Destination Network Address Translation (NAT)** | Modifica la dirección IP de destino de los paquetes entrantes, a menudo se utiliza para dirigir el tráfico a un servidor o servicio interno específico.                                                                |
| **Endpoint Detection and Response (EDR)**         | Herramientas y prácticas de ciberseguridad diseñadas para detectar, investigar y responder a actividades sospechosas en puntos finales como computadoras de escritorio, portátiles, servidores y dispositivos móviles. |
| **File Integrity Monitoring (FIM)**               | Proceso de ciberseguridad que verifica continuamente la integridad de los archivos de software del sistema y las aplicaciones comparándolos con una línea base confiable.                                              |
| **Firewall**                                      | Dispositivo o software de seguridad que monitorea y controla el tráfico de red entrante y saliente según reglas de seguridad predeterminadas.                                                                          |
| **Host-Based IDS (HIDS)**                         | Sistemas de detección de intrusos instalados en hosts individuales que monitorean registros del sistema, modificaciones de archivos y actividades de procesos.                                                         |
| **Host-Based Intrusion Prevention System (HIPS)** | Desplegado en hosts individuales para proteger el dispositivo a nivel de punto final mediante el bloqueo de actividades sospechosas.                                                                                   |
| **Intrusion Detection System (IDS)**              | Tecnología de seguridad de red diseñada para monitorear el tráfico en busca de actividades sospechosas y posibles amenazas.                                                                                            |
| **Intrusion Prevention System (IPS)**             | Se basa en las capacidades del IDS para no solo detectar amenazas, sino también tomar medidas proactivas para bloquearlas o mitigarlas.                                                                                |
| **Network Address Translation (NAT)**             | Proporciona una capa de seguridad adicional entre redes públicas y privadas modificando la información de la dirección de red en los encabezados IP.                                                                   |
| **Network-Based IDS (NIDS)**                      | Sistemas de detección de intrusos que monitorean los patrones de tráfico en toda la red para señalar anomalías e intentos de acceso no autorizados.                                                                    |
| **Port Address Translation (PAT)**                | También conocido como sobrecarga de NAT, mapea múltiples direcciones IP privadas a una sola dirección IP pública con diferentes números de puerto para cada sesión.                                                    |
| **Static NAT**                                    | Traducción de direcciones de red que mapea una sola dirección IP privada a una sola dirección IP pública, proporcionando una dirección externa fija.                                                                   |
| **Synergistic Security Approach**                 | El uso combinado de filtros de firewall, IDS e IPS para crear un mecanismo de defensa integral donde el firewall aplica políticas y los sistemas IDS/IPS brindan protección dinámica.                                  |
| **VLAN**                                          | Virtual Local Area Network, utilizada para segmentar el tráfico de red y gestionar el flujo de datos dentro de una red.                                                                                                |
