# Glosario: Protocolos de Red

Este glosario detallado presenta los protocolos y términos técnicos fundamentales para la gestión, el monitoreo y la seguridad de las comunicaciones en red.

| Término                                        | Definición                                                                                                                        |
| :--------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------- |
| **Acknowledgment number (Número ACK)**         | Número en TCP que indica el siguiente paquete esperado en la secuencia, confirmando la recepción de los anteriores.               |
| **Data exfiltration (Exfiltración de datos)**  | Transferencia no autorizada de datos sensibles fuera de una organización, detectada usualmente por patrones inusuales de tráfico. |
| **DHCP Acknowledgment (ACK)**                  | Mensaje enviado por el servidor DHCP que confirma que una dirección IP ha sido otorgada al dispositivo solicitante.               |
| **DHCP Discover**                              | Mensaje inicial enviado por un dispositivo para localizar un servidor DHCP disponible en la red.                                  |
| **DHCP Handshake (Saludo DHCP)**               | Secuencia de cuatro mensajes (Discover, Offer, Request, Acknowledgment) para obtener una dirección IP automáticamente.            |
| **Domain Name System (DNS)**                   | Servicio de red que traduce nombres de dominio legibles para humanos en direcciones IP.                                           |
| **Dynamic Host Configuration Protocol (DHCP)** | Protocolo que asigna automáticamente direcciones IP desde un grupo gestionado por un servidor DHCP.                               |
| **Egressing (Egreso)**                         | El proceso por el cual los datos salen a través de una interfaz de red.                                                           |
| **Hypertext Transfer Protocol (HTTP)**         | Protocolo utilizado para la navegación web, operando en un ciclo de solicitud-respuesta.                                          |
| **Hypertext Transfer Protocol Secure (HTTPS)** | Versión segura de HTTP que utiliza certificados SSL para cifrar los datos durante la comunicación.                                |
| **Internet Control Message Protocol (ICMP)**   | Protocolo de red utilizado para enviar mensajes de error e información operativa (como el comando ping).                          |
| **Internet Protocol Television (IPTV)**        | Servicio que transmite señales de TV usando UDP y TCP, dependiendo del servicio y la dirección del tráfico.                       |
| **MAC Address (Dirección MAC)**                | Identificador único asignado a las interfaces de red para comunicaciones en el segmento físico de la red.                         |
| **Quality of Service (QoS)**                   | Información sobre la calidad del servicio de red, incluyendo el tipo de servicio y el uso de protocolos.                          |
| **Remote Switch Port Analyzer (RSPAN)**        | Tipo de duplicación de puertos que permite que el puerto de destino esté en un switch diferente al de origen.                     |
| **Simple Mail Transfer Protocol (SMTP)**       | Protocolo estándar utilizado para el envío de correos electrónicos.                                                               |
| **Simple Network Management Protocol (SNMP)**  | Protocolo para monitorear y gestionar dispositivos de red que puede utilizar tanto UDP como TCP.                                  |
| **Syslog**                                     | Estándar para el registro de mensajes que separa la generación, el almacenamiento y el análisis de los mismos.                    |
| **Transmission Control Protocol (TCP)**        | Protocolo orientado a la conexión que garantiza la entrega confiable y ordenada de datos mediante un saludo de tres vías.         |
| **Trivial File Transfer Protocol (TFTP)**      | Protocolo simple de transferencia de archivos que utiliza UDP para archivos muy pequeños sin sobrecarga de conexión.              |
| **User Datagram Protocol (UDP)**               | Protocolo sin conexión que permite enviar paquetes rápidamente sin establecer un enlace previo.                                   |
| **Voice-over IP (VoIP)**                       | Protocolo para transmitir voz sobre Internet; típicamente usa UDP, aunque también puede usar TCP.                                 |
| **Web Traffic (Tráfico Web)**                  | Tráfico de red relacionado con la navegación y los protocolos HTTP/HTTPS.                                                         |
| **Wireshark**                                  | Analizador de protocolos de red utilizado para capturar y examinar el tráfico en tiempo real.                                     |
