# Glosario: Fundamentos de Redes

Este glosario contiene términos clave sobre infraestructura, protocolos y modelos de red, esenciales para entender la comunicación y seguridad en entornos digitales.

| Término                                        | Definición                                                                                                                                    |
| :--------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------- |
| **Address Resolution Protocol (ARP)**          | Protocolo utilizado para resolver problemas de red y configurar nuevos dispositivos.                                                          |
| **Bridge (Puente)**                            | Dispositivo que conecta dos o más redes separadas, permitiendo que funcionen como una sola.                                                   |
| **Clientes**                                   | Dispositivos que acceden a un servidor para solicitar recursos o servicios.                                                                   |
| **Domain Name System (DNS)**                   | Protocolo que resuelve o traduce nombres de dominio (como google.com) en direcciones IP.                                                      |
| **Dynamic Host Configuration Protocol (DHCP)** | Protocolo que automatiza la asignación de direcciones IP y configuraciones a los dispositivos de una red.                                     |
| **File Transfer Protocol (FTP)**               | Protocolo responsable de la transferencia de archivos entre sistemas.                                                                         |
| **Firewall (Cortafuegos)**                     | Hardware o software que controla el tráfico entrante y saliente basado en reglas de seguridad predeterminadas.                                |
| **Gateway (Puerta de enlace)**                 | Hardware o software que permite que los datos fluyan de una red a otra, utilizando múltiples protocolos para conectarlas.                     |
| **Hub (Concentrador)**                         | Dispositivo que conecta múltiples equipos en una red; transmite los datos recibidos a todos los dispositivos conectados excepto al remitente. |
| **Hypertext Transfer Protocol (HTTP)**         | Protocolo estándar para el acceso a páginas web en Internet.                                                                                  |
| **Hypertext Transfer Protocol Secure (HTTPS)** | Versión cifrada de HTTP para acceso web seguro, esencial en páginas que manejan datos sensibles.                                              |
| **IMAP4**                                      | Protocolo para recibir correos; los mensajes se almacenan en el servidor y se sincronizan con múltiples dispositivos.                         |
| **Intrusion Detection System (IDS)**           | Herramienta de seguridad que monitorea la actividad de la red en busca de comportamientos maliciosos o violaciones de políticas.              |
| **Intrusion Prevention System (IPS)**          | Dispositivo o software que detecta y previene o elimina activamente actividades maliciosas.                                                   |
| **IPv4**                                       | Protocolo de comunicación que identifica dispositivos mediante direcciones de 32 bits expresadas en notación decimal.                         |
| **IPv6**                                       | Evolución de IP que extiende las direcciones a 128 bits, permitiendo un mayor número de dispositivos conectados.                              |
| **Modems**                                     | Dispositivo que convierte datos en un formato apto para la transmisión por red y los decodifica al llegar a su destino.                       |
| **Network Interface Cards (NIC)**              | Hardware (cableado o inalámbrico) que permite a un dispositivo conectarse a una red.                                                          |
| **Open Systems Interconnection Model (OSI)**   | Marco conceptual de siete capas que describe las funciones de un sistema de red.                                                              |
| **Post Office Protocol version 3 (POP3)**      | Protocolo antiguo para recibir correos; descarga los mensajes a un solo dispositivo y los elimina del servidor.                               |
| **Remote Desktop Protocol (RDP)**              | Protocolo utilizado para controlar remotamente otra computadora a través de una interfaz gráfica.                                             |
| **Router (Enrutador)**                         | Dispositivo que conecta diferentes redes o subredes y dirige los paquetes de datos entre ellas.                                               |
| **Secure Shell (SSH)**                         | Protocolo para controlar dispositivos de forma remota mediante una consola segura y cifrada.                                                  |
| **Server (Servidor)**                          | Computadora potente que almacena archivos y aplicaciones para que otros dispositivos accedan a ellos.                                         |
| **Simple Message Transport Protocol (SMTP)**   | Protocolo responsable del envío de correos electrónicos.                                                                                      |
| **Switch (Conmutador)**                        | Dispositivo que conecta equipos en una red y reenvía los datos específicamente al dispositivo de destino usando su dirección MAC.             |
| **TCP (Transmission Control Protocol)**        | Protocolo que garantiza que los datos lleguen a su destinatario; es confiable pero más lento y consume más recursos.                          |
| **TCP/IP Model**                               | Conjunto de estándares de cuatro capas que permiten la comunicación de computadoras en una red.                                               |
| **User Datagram Protocol (UDP)**               | Protocolo de Internet rápido y eficiente para enviar mensajes; no garantiza que todos los paquetes lleguen.                                   |
| **Wireless Access Point (WAP)**                | Dispositivo que permite a equipos Wi-Fi conectarse a una red cableada.                                                                        |
| **WLAN (Wireless Local-Area Network)**         | Red inalámbrica que conecta dispositivos en hogares u oficinas usando señales Wi-Fi (IEEE 802.11).                                            |
| **WWAN (Wireless Wide Area Network)**          | Red inalámbrica de cobertura regional o global, como las redes celulares 4G, 5G y LTE.                                                        |
