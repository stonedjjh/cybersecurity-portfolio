# Glosario: Direccionamiento IP, Enrutamiento y Conmutación

Este glosario abarca términos fundamentales sobre protocolos de comunicación, mecanismos de conexión y servicios de red esenciales para el intercambio de datos.

| Término                   | Definición                                                                                                           |
| :------------------------ | :------------------------------------------------------------------------------------------------------------------- |
| **ACK (Acuse de recibo)** | Mensaje enviado por el receptor para indicar la recepción exitosa de un paquete de datos.                            |
| **DHCP**                  | Protocolo que asigna automáticamente direcciones IP a los dispositivos dentro de una red.                            |
| **FTP**                   | Protocolo utilizado para la transferencia de archivos entre un cliente y un servidor en una red.                     |
| **HTTP**                  | Protocolo base para la comunicación de datos en la World Wide Web.                                                   |
| **HTTPS**                 | Versión cifrada y segura de HTTP para la comunicación protegida en redes informáticas.                               |
| **IPTV**                  | Entrega de contenido de televisión a través de redes que utilizan el protocolo de Internet.                          |
| **SMTP**                  | Protocolo utilizado para enviar y enrutar correos electrónicos entre servidores de correo.                           |
| **SNMP**                  | Protocolo que recopila y organiza información sobre dispositivos administrados en redes IP.                          |
| **SSL**                   | Protocolo antiguo (actualmente en desuso) para establecer enlaces cifrados entre un servidor web y un navegador.     |
| **Solicitud SYN**         | El paquete inicial en el saludo de tres vías de TCP para establecer una conexión.                                    |
| **TCP**                   | Protocolo que proporciona una entrega de paquetes de datos confiable, ordenada y verificada contra errores.          |
| **Saludo de tres vías**   | Proceso utilizado en TCP para establecer una conexión formal entre un cliente y un servidor.                         |
| **TFTP**                  | Versión simplificada de FTP que permite a un cliente obtener o colocar archivos en un host remoto de forma sencilla. |
| **UDP**                   | Protocolo sin conexión para enviar mensajes con mecanismos de protocolo mínimos, priorizando la velocidad.           |
| **VoIP**                  | Tecnología que permite realizar llamadas de voz utilizando una conexión a Internet de banda ancha.                   |
