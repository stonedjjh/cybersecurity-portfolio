# Asignación de competencias a funciones laborales

---

| Rol del puesto | Habilidades más solicitadas |
| :--- | :--- |
| **Especialista en ciberseguridad** | Gestión de vulnerabilidades, Sistemas de información, Fundamentos de programación, Auditoría, Análisis de requisitos de seguridad, Sistemas operativos y Gestión de riesgos. |
| **Analista de ciberdelincuencia** | Análisis forense digital, Fundamentos de programación, Respuesta a incidentes e Inteligencia sobre amenazas. |
| **Analista de incidentes e intrusiones** | Respuesta a incidentes, Conceptos básicos de programación, SIEM, Sistemas operativos, Sistemas de información, Seguridad de redes e Inteligencia sobre amenazas. |
| **Auditor de TI** | Auditoría, Contabilidad y finanzas, Controles internos, Fundamentos de programación, Sistemas de información y Análisis de datos. |
| **Analista de ciberseguridad** | Fundamentos de programación, Gestión de vulnerabilidades, Auditoría, Respuesta a incidentes, Gestión de riesgos, Seguridad de redes e Inteligencia sobre amenazas. |
| **Consultor de ciberseguridad** | Auditoría, Seguridad física, Ciberseguridad, Gestión de crisis, Técnicas de desescalada, Programación, Seguridad de redes e Inteligencia sobre amenazas. |
| **Probador de penetración (Pentester)** | Programación (especialmente Python), Gestión de vulnerabilidades, Seguridad de redes, Pruebas de penetración y Auditoría. |
| **Gestor de ciberseguridad** | Auditoría, Gestión de vulnerabilidades, Seguridad de redes, Programación, Sistemas de información, Controles y Análisis de riesgos. |
| **Ingeniero de ciberseguridad** | Seguridad de redes, Programación (especialmente Python), Gestión de vulnerabilidades, Auditoría, Automatización y Análisis de riesgos. |
| **Arquitecto de ciberseguridad** | Seguridad de redes, Arquitectura de seguridad, Fundamentos de programación, Arquitectura de soluciones y Gestión de vulnerabilidades. |
