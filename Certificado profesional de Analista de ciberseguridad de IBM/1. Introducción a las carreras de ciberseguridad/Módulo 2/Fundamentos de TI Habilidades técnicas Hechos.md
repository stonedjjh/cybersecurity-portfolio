# Habilidades Técnicas en Ciberseguridad

| Habilidad                   | Descripción y Conceptos Clave                                                                                                                                   |
| :-------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Hardware**                | Comprender arquitectura informática, componentes, interfaces, solución de averías, vulnerabilidades físicas, configuración, instalación y mantenimiento.        |
| **Sistemas Operativos**     | Manejo de Windows, MacOS y Linux. Gestión de procesos, hilos, memoria, sistemas de archivos, permisos de usuario, registros (logs) y supervisión.               |
| **Redes**                   | Estructura de redes, protocolos, modelo OSI, diagnóstico de problemas, herramientas de monitoreo, seguridad (firewalls, IDS) y redes inalámbricas.              |
| **Programación**            | Lenguajes (Python, JavaScript), estructuras de datos, algoritmos, codificación segura, depuración y scripts para automatización de seguridad.                   |
| **Bases de Datos**          | Tipos (relacionales, NoSQL, en memoria), esquemas, administración (backups, restauración), replicación y control de acceso mediante permisos y roles.           |
| **Nube (Cloud)**            | Modelos de servicio (IaaS, PaaS, SaaS), modelo de responsabilidad compartida, tipos de despliegue (pública, privada, híbrida) y seguridad en el almacenamiento. |
| **Automatización**          | Automatización de configuración, despliegue y gestión de redes. Evaluación de riesgos y beneficios de sistemas automatizados en la organización.                |
| **Sistemas de Información** | Integración de hardware, software, datos y recursos humanos para procesar y distribuir información. Análisis, diseño y gestión de sistemas complejos.           |
