# Glosario de Términos Técnicos en Ciberseguridad

A continuación se presentan los conceptos fundamentales para la gestión de infraestructura y seguridad.

| Término                         | Definición                                                                                                                                         |
| :------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Automatización**              | Automatizar la configuración, operación, despliegue, pruebas y gestión de dispositivos virtuales y físicos dentro de una red.                      |
| **Nube**                        | Una red de servidores alojados en internet para almacenar, gestionar y procesar datos como alternativa a un servidor local o computadora personal. |
| **Habilidad en bases de datos** | Conocimiento de tipos de bases de datos, esquemas, administración y el uso de permisos y roles para limitar el acceso a datos sensibles.           |
| **Sistemas de Archivos**        | Estructuras que organizan y aseguran los datos dentro de un sistema.                                                                               |
| **Sistemas de Información**     | Combinación de hardware, software, datos y recursos humanos para recolectar, procesar, almacenar y distribuir información en una organización.     |
| **Gestión de Memoria**          | Proceso del sistema operativo que afecta directamente el rendimiento y la seguridad del sistema.                                                   |
| **Habilidades de Redes**        | Entender la estructura y funciones de redes, protocolos, modelos OSI, resolución de problemas, monitoreo y medidas de seguridad.                   |
| **Fundamentos de Programación** | Incluye lenguajes, estructuras de datos, algoritmos, codificación segura, interpretación de código, depuración y scripts de automatización.        |
| **Gestión de Riesgos**          | Proceso de identificar, evaluar y priorizar riesgos, implementando recursos para minimizar su impacto.                                             |
| **Operaciones de Seguridad**    | Mantener y monitorear la infraestructura, responder a incidentes, asegurar el cumplimiento y colaborar con otros equipos de TI.                    |
| **Gestión de Amenazas**         | Proceso utilizado para prevenir ciberataques, detectar amenazas cibernéticas y responder a incidentes de seguridad.                                |
| **Permisos y Roles de Usuario** | Mecanismos dentro de un sistema operativo para limitar el acceso a datos sensibles según el perfil del usuario.                                    |
| **Gestión de Vulnerabilidades** | Descubrimiento continuo, priorización y resolución de fallos de seguridad en la infraestructura y hardware de una organización.                    |
