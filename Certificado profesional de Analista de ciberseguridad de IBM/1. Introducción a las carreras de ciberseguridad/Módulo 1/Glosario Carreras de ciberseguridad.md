# Glosario: Carreras de ciberseguridad

| Término | Definición |
| :--- | :--- |
| **Activos de información** | Los datos que una organización utiliza para operar y tomar decisiones. |
| **Análisis de sistemas** | Los estudios realizados para entender la función de un sistema y diseñar estrategias de mejora. |
| **Analista de cibercrimen** | Predicen posibles ataques futuros basándose en datos históricos y tendencias actuales, y ayudan a desarrollar estrategias de defensa robustas. |
| **Analista de incidentes e intrusiones** | El rol es responsable de detectar y responder a brechas de ciberseguridad, identificar la fuente y evaluar la extensión del daño. |
| **Aprendizaje continuo** | La búsqueda continua, voluntaria y autónoma de conocimiento por razones personales o profesionales. |
| **Arquitectos de ciberseguridad** | Desarrollan un marco integral que detalla cómo interactuarán y se apoyarán mutuamente los diversos elementos de seguridad. |
| **Atacante** | Un individuo que identifica y explota vulnerabilidades del sistema de manera poco ética. |
| **Auditor de TI** | Son responsables de examinar y evaluar críticamente los sistemas, prácticas y operaciones de TI de una organización. |
| **Auditorías de seguridad** | Las evaluaciones regulares realizadas para medir la efectividad de la arquitectura de seguridad y el cumplimiento de regulaciones y mejores prácticas. |
| **Carrera de nivel inicial** | El punto de partida de una carrera que a menudo tiene un salario más bajo y requiere menos experiencia o capacitación. |
| **Ciberseguridad** | La práctica de proteger computadoras, servidores, dispositivos móviles, sistemas electrónicos, redes y datos de ataques digitales. |
| **CISO (Director de Seguridad de la Información)** | El ejecutivo de más alto nivel responsable de establecer y mantener la visión, estrategia y programas de seguridad de una empresa. |
| **Consultor de ciberseguridad** | Actúan como expertos externos, proporcionando orientación y recomendaciones a las organizaciones para mejorar su marco de seguridad y mitigar amenazas potenciales. |
| **Cortafuegos** | El dispositivo de seguridad de red que monitorea y controla el tráfico de red entrante y saliente según reglas de seguridad predefinidas. |
| **Cumplimiento** | La adherencia a regulaciones de privacidad, políticas de seguridad empresarial y mejores prácticas en ciberseguridad. |
| **Diseño e implementación de ciberseguridad** | El proceso de diseñar y establecer medidas para proteger los activos digitales de una organización. |
| **Especialista en ciberseguridad** | Monitorean sistemas en busca de amenazas potenciales, analizan y evalúan brechas de seguridad, e implementan medidas de seguridad adecuadas para prevenir futuros ciberataques. |
| **Gerente de ciberseguridad** | Desarrollan e implementan políticas de seguridad, gestionan un equipo de profesionales de ciberseguridad y se comunican con la alta dirección sobre todos los temas relacionados con la seguridad. |
| **Ingeniero de ciberseguridad** | Diseñan y crean redes, sistemas y arquitecturas de aplicaciones seguras. |
| **Investigador de seguridad ofensiva** | Identifican y explotan vulnerabilidades del sistema de manera ética y controlada. Realizan análisis exhaustivos del sistema, documentan el proceso de prueba y recomiendan medidas de seguridad. |
| **Mediana** | El número medio en una lista ordenada de números. |
| **Planificación de respuesta a incidentes** | Las actividades coordinadas para responder a una brecha de seguridad, incluyendo análisis post-incidente y estrategias de medidas preventivas. |
| **Probador de penetración y vulnerabilidad** | Responsables de identificar debilidades y vulnerabilidades en el sistema al sondear y explotarlas deliberadamente, imitando las acciones de posibles atacantes. |
| **Protocolos de encriptación** | Son medidas de seguridad implementadas para proteger información sensible contra accesos no autorizados, modificaciones o destrucción. |
| **Rango** | La diferencia entre los valores más bajo y más alto. |
| **Redes** | El proceso de interactuar con otros para intercambiar información y desarrollar contactos profesionales o sociales. |
| **Rutas académicas** | Las vías educativas formales que conducen a un diploma o título. |
| **Sistemas de detección de intrusiones** | Las medidas avanzadas de ciberseguridad que se implementan para detectar amenazas potenciales a la información digital y activos de TI de la organización. |
| **Vulnerabilidades** | Los puntos débiles en un sistema que actores maliciosos podrían potencialmente explotar. |
