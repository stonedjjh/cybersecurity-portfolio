# Técnicas de navegación segura

La seguridad en la navegación depende de una configuración adecuada de las funciones de conveniencia (autocompletado, caché) y de la capacidad de identificar sitios web y software malicioso.

## 1. Gestión de Datos del Navegador

- **Autocompletado (Autofill):** Guarda contraseñas, métodos de pago y direcciones. Es útil pero riesgoso en dispositivos compartidos; se recomienda usar cuentas de invitado en esos casos.
- **Memoria Caché:** Almacena copias de páginas web para acelerar la carga. Si es muy grande, puede ralentizar el sistema.
- **Historial de Navegación:** Lista de sitios visitados. Puede ser usado por terceros para rastrear actividades pasadas.

## 2. Navegación Privada (Modo Incógnito)

Es una herramienta de privacidad local, no de anonimato total.

- **Lo que hace:** Elimina cookies, historial y datos de formularios al cerrar la sesión. Te hace aparecer como un "usuario nuevo" en los sitios.
- **Lo que NO hace:** No oculta tu actividad a tu empleador, escuela o proveedor de Internet (ISP). No oculta los archivos que descargues ni los marcadores que crees.

## 3. Identificación de Sitios Web Maliciosos

Los atacantes crean sitios que imitan a los reales para robar datos o instalar malware.

- **Señales de alerta:** - Errores tipográficos en la URL (ej. usar un "0" en lugar de una "O").
  - Diseño web inconsistente o de baja calidad.
  - Falta de información de contacto en herramientas como **Whois**.
- **Consejos de seguridad:** Buscar reseñas en foros (como Reddit), verificar sellos de confianza y utilizar exclusivamente sitios **HTTPS**.

## 4. Adware y Redirecciones

El **Adware** es malware diseñado para mostrar anuncios no deseados, a menudo incluido en aplicaciones gratuitas.

- **Consecuencias:** Ralentización del sistema, cambios en la página de inicio, aparición de nuevas barras de herramientas y rastreo de actividad.
- **Redirecciones:** Software malicioso que sabotea las búsquedas o las URL introducidas para llevar al usuario a sitios publicitarios o peligrosos.
- **Prevención:** Mantener actualizaciones automáticas, realizar escaneos periódicos y hacer caso a las advertencias del navegador sobre sitios no seguros.
