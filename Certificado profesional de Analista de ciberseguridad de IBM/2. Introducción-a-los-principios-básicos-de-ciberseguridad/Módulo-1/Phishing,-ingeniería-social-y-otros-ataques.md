# Suplantación de identidad, ingeniería social y otros ataques

## 1. Suplantación de Identidad (Spoofing)

La suplantación ocurre cuando un atacante finge ser una entidad o persona legítima para engañar a las víctimas.

1. Gemelo malvado (Evil Twin): Configuración de una red Wi-Fi pública falsa que imita una legítima para interceptar PII y credenciales.
2. Sitios web falsos: Creación de portales que replican visualmente sitios reales para capturar datos de inicio de sesión.
3. Suplantación de identidad personal: Hacerse pasar por otra persona para ganar acceso a sistemas o datos.

## 2. Ingeniería Social

A diferencia de los ataques técnicos que explotan vulnerabilidades de software, la ingeniería social explota el error humano mediante la manipulación psicológica.

1. Mecanismos de presión: Uso de miedo, urgencia, autoridad o simpatía para forzar acciones rápidas.
2. Alcance: Se estima que está presente en el 90% de las brechas de seguridad actuales.

## 3. Tipos de Ataques de Ingeniería Social

1. Shoulder Surfing (Mirar sobre el hombro): Espionaje físico en lugares públicos para obtener PINs, contraseñas o nombres de usuario.
2. Baiting (Señuelo): Uso de objetos físicos (como memorias USB dejadas en público) o señuelos lógicos (software gratuito) para que la víctima infecte su propio sistema.
3. Pretexting: El atacante crea un escenario falso donde se hace pasar por una figura de autoridad (soporte técnico, administrador del banco) para solicitar datos sensibles.

## 4. Phishing y sus Variaciones

El phishing utiliza comunicaciones digitales para engañar a los usuarios y robar sus credenciales o instalar malware.

1. Phishing general: Correos o mensajes masivos que crean falsa urgencia.
2. Spear Phishing: Ataque dirigido específicamente a un individuo u organización.
3. Whaling (Caza de ballenas): Phishing dirigido a ejecutivos de alto nivel.
4. Vishing: Phishing realizado a través de llamadas telefónicas.

## 5. Robo y Fraude de Identidad

1. Robo de identidad: El acto de sustraer información personal o financiera. Los delincuentes suelen utilizar datos de personas fallecidas o niños para evitar ser detectados rápidamente.
2. Fraude de identidad: El uso de la información robada para abrir cuentas, solicitar préstamos o cometer otros delitos financieros.

## 6. Medidas de Prevención y Mitigación

1. Uso de pantallas de privacidad y vigilancia del entorno en lugares públicos.
2. No dejar dispositivos desatendidos ni conectar dispositivos USB de procedencia desconocida.
3. Nunca utilizar redes Wi-Fi públicas para manejar información sensible.
4. Verificar la autenticidad de cualquier solicitud de datos, incluso si parece provenir de una autoridad.
5. Monitorear regularmente las cuentas financieras para detectar actividad inusual.
