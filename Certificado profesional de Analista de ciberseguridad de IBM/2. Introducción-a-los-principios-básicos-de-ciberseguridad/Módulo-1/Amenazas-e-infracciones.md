# Amenazas y Vulnerabilidades (Threats and Breaches)

## 1. Amenazas Físicas y de Hardware

El hardware es el activo más vulnerable si no existen políticas de seguridad física estrictas. Es más sencillo robar datos directamente de un servidor o portátil que realizar un hackeo remoto complejo.

1. Protección de instalaciones: Uso de áreas cerradas, lectores de tarjetas y vigilancia constante.
2. Infraestructura ambiental: Mantenimiento de sistemas HVAC (calefacción, ventilación y aire acondicionado) para evitar humedad y moho, junto con sistemas de extinción de incendios.
3. Resiliencia: Implementación de energía de respaldo y planes de recuperación ante desastres naturales (terremotos, inundaciones, tormentas).

## 2. Filtraciones y Exposición de Datos

La pérdida de información sensible puede ocurrir de forma accidental o mediante ataques dirigidos.

1. Filtraciones (Breaches): Exposición de datos por vulnerabilidades de seguridad.
2. Ingeniería Social: Engaño a empleados para obtener credenciales.
3. Volcados de datos (Data Dumps): Publicación de información robada (PII, PHI, PINs) en la web oscura para su venta.
4. Dumpster Diving (Buceo en contenedores): Búsqueda física de información en la basura, como códigos de acceso en notas o diseños de productos. Requiere la destrucción obligatoria de documentos y dispositivos.

## 3. Amenazas Internas

Riesgos que provienen de individuos dentro de la organización.

1. Empleados malintencionados: Venta de información confidencial o sabotaje.
2. Errores accidentales: Entrega involuntaria de credenciales o datos.
3. Chantaje: Reclutamiento de empleados por parte de hackers externos mediante amenazas o sobornos.

## 4. Software y Malware

El malware es software diseñado para comprometer sistemas, ralentizarlos o robar información.

1. Robo de software: Uso no autorizado o piratería de licencias protegidas.
2. Exploits: Código que aprovecha vulnerabilidades específicas en hardware o software para entrar al sistema.
3. Drive-by downloads: Descargas automáticas de malware al visitar sitios web infectados.
4. Vectores de ataque: Correos, unidades USB, anuncios y ataques de protocolo de escritorio remoto (RDP).

## 5. Tipos de Malware y Diferencias Clave

Es fundamental distinguir cómo se propagan y actúan los distintos códigos maliciosos:

1. Virus: Requieren que un usuario inicie el archivo infectado. Incluyen virus de programa, macrovirus (Office), virus sigilosos y virus polimórficos (que cambian sus rasgos para evadir defensas).
2. Gusanos: A diferencia de los virus, se activan solos tras identificar debilidades en el sistema y pueden controlarse de forma remota.
3. Troyanos: Engañan al usuario simulando ser software legítimo para instalar contenido dañino.
4. Spyware y Adware: Recopilan actividad en línea y datos personales. Pueden ser legítimos o malintencionados.
5. Ransomware: Cifra archivos y bloquea el sistema exigiendo un rescate. La mejor defensa es una restauración completa desde una copia de seguridad.

## 6. Prevención General

Para mitigar estas amenazas, se establecen las siguientes medidas:

1. Mantener todo el software actualizado con parches de seguridad.
2. Utilizar software antivirus sólido.
3. Realizar copias de seguridad (backups) de forma regular.
4. Fomentar el uso de contraseñas seguras y su rotación frecuente.
