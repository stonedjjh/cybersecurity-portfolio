# Glossary: Cybersecurity Insights

| Term                                                                            | Definition                                                                                                                                                                                                                                                                                                                 |
| :------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Access control                                                                  | A security feature that restricts and regulates who can view or use resources in a computing system.                                                                                                                                                                                                                       |
| Active sniffing                                                                 | A technique used in network security to actively intercept and examine data packets traveling across a network.                                                                                                                                                                                                            |
| Address resolution protocol (ARP)                                               | A networking protocol used to map an IP address to a physical media access control (MAC) address within a local network.                                                                                                                                                                                                   |
| Administrative controls                                                         | A category of security controls that establishes guidelines and methodologies to ensure employees and stakeholders adhere to proper security protocols.                                                                                                                                                                    |
| Adware                                                                          | A malicious software that displays unwanted advertisements on a user's device.                                                                                                                                                                                                                                             |
| Advanced persistent threat (APT)                                                | A sophisticated cyberattack wherein attackers move laterally within the network, undetected, elevating privileges until they can access critical data or take control of system functions.                                                                                                                                 |
| Advanced Research Projects Agency Network (ARPANET)                             | The first wide-area, packet-switched network with distributed control and one of the first computer networks to implement the TCP/IP protocol suite.                                                                                                                                                                       |
| Antivirus software                                                              | A critical tool for system security that serves as the first line of defense against viruses and malware.                                                                                                                                                                                                                  |
| Backup                                                                          | The task of creating copies of data from a system so it can be restored in case of data loss due to hardware failure, data corruption, or a cyberattack.                                                                                                                                                                   |
| Bot                                                                             | An automated software that performs malicious tasks over the internet. The bot malware works alongside other computers infected with the same malware to create a botnet. This botnet is controlled by a command-and-control server responsible for sending out commands.                                                  |
| Botnet                                                                          | A collection of interconnected computers centrally controlled by one or more attackers. Each compromised computer runs a specialized bot program to perform malicious tasks on behalf of the attackers.                                                                                                                    |
| Bring-your-own-device (BYOD)                                                    | A business policy that permits employees to use personal devices for work-related tasks.                                                                                                                                                                                                                                   |
| Chain of custody                                                                | A documented trail that provides a clear record of who accessed the evidence, when it was accessed, and what actions were taken.                                                                                                                                                                                           |
| CIA triad                                                                       | A fundamental concept in cybersecurity that represents three core principles: confidentiality, integrity, and availability.                                                                                                                                                                                                |
| Containment                                                                     | A set of actions taken to limit the damage caused by an incident. These actions may involve isolating affected systems or taking them offline temporarily.                                                                                                                                                                 |
| Corrective controls                                                             | A category of security controls implemented to address the consequences of a security violation. These controls incorporate strategies to mitigate the impacts of an incident and prevent its recurrence.                                                                                                                  |
| Critical thinking                                                               | A capability of objectively analyzing information and forming reasoned judgments.                                                                                                                                                                                                                                          |
| Critical thinking model                                                         | A model that comprises five elements: characteristics of thought, technical skills, interpersonal skills, theoretical and experimental knowledge, and intellectual abilities.                                                                                                                                              |
| Cross-site scripting (XSS) attack                                               | A security breach where attackers embed harmful scripts into web pages that are usually considered safe.                                                                                                                                                                                                                   |
| Cybersecurity and Infrastructure Security Agency (CISA)                         | A United States agency responsible for cybersecurity and infrastructure protection across all levels of government.                                                                                                                                                                                                        |
| Deep fakes                                                                      | A technology that simulates voice, image, likeness of an individual.                                                                                                                                                                                                                                                       |
| Defense in depth                                                                | A comprehensive approach to cybersecurity that involves implementing multiple layers of security controls and measures across an organization's IT infrastructure to protect against a range of threats and vulnerabilities.                                                                                               |
| Department of Homeland Security (DHS)                                           | A department to safeguard the nation from physical and cyber threats.                                                                                                                                                                                                                                                      |
| Detective controls                                                              | A category of security controls that play a critical role in identifying and alerting to any improper or unauthorized actions occurring within an organization.                                                                                                                                                            |
| Deterrent controls                                                              | A category of security controls that discourages deviations from established security procedures and decreases the likelihood of intentional attacks. These controls facilitate informed decision-making and discourage the use of insecure methods.                                                                       |
| Digital forensics                                                               | A branch of forensic science that provides the tools and techniques required to collect and analyze digital evidence, aiding in understanding the nature of the incident and its implications.                                                                                                                             |
| Distributed denial-of-service (DDoS)                                            | A malicious attempt to interrupt the routine functioning of a server, service, or network by flooding it with traffic from multiple sources.                                                                                                                                                                               |
| Domain name server (DNS)                                                        | A phonebook of the internet, translates domain names to IP addresses so browsers can load internet resources.                                                                                                                                                                                                              |
| Domain name system (DNS) falsification                                          | A cyberattack where attackers corrupt or alter DNS records in a DNS resolver's cache to redirect users to malicious websites or servers.                                                                                                                                                                                   |
| Document object model (DOM)                                                     | An object-based interface developed by the World Wide Web Consortium (W3C) that creates an XML document as a tree-like structure in memory. DOM pertains to the data structures defined inside the web browser program, which describe the contents of a web page.                                                         |
| Dumpster diving                                                                 | An attack that involves searching through an individual's or company's discarded items for valuable data.                                                                                                                                                                                                                  |
| Dynamic application security testing (DAST)                                     | A type of security testing that involves executing code during evaluation and probing all user-facing interfaces with varied inputs to find potential security issues.                                                                                                                                                     |
| Egress filtering                                                                | A technique used to protect your network from IP spoofing. Egress filtering scrutinizes outgoing IP packets, verifying that they possess authentic source headers to deter individuals inside the network from exporting spoofed packets as part of an offensive IP spoofing campaign.                                     |
| Encryption                                                                      | The process of converting information into code, rendering the original content unreadable to those without the key to decrypt it.                                                                                                                                                                                         |
| Endpoint security                                                               | The practice of securing endpoints, such as computers, mobile devices, and servers, within a network from cyberattacks. Endpoint security plays a pivotal role in organizational security as endpoints serve as potential entry points for attackers.                                                                      |
| Error handling                                                                  | The process of responding to and managing errors that arise during the operation or execution of applications.                                                                                                                                                                                                             |
| Fileless malware                                                                | A form of malicious software that operates within computer memory without leaving any traces on the file system.                                                                                                                                                                                                           |
| Firewalls                                                                       | A hardware or software barrier that filters out and prevents unauthorized or malicious data traffic from entering or leaving a network.                                                                                                                                                                                    |
| Foreign Intelligence Surveillance Court (FISC)                                  | A foreign intelligence surveillance court entertains applications made by the United States Government for approval of electronic surveillance, physical search, and certain other forms of investigative actions for foreign intelligence purposes.                                                                       |
| Full-disk encryption                                                            | A security technique that encrypts every file and piece of data on the drive, rendering the contents of the entire disk inaccessible without the password or decryption key. Full-disk encryption protects sensitive data if a laptop or external drive is lost or stolen.                                                 |
| General data protection regulation (GDPR)                                       | A regulation that lists the rights of the data subject, meaning the rights of the individuals whose personal data is being processed.                                                                                                                                                                                      |
| General phishing                                                                | A phishing attack where attackers send emails to a mass group and see who responds.                                                                                                                                                                                                                                        |
| Hacktivist                                                                      | A threat actor who is motivated by political or social agendas.                                                                                                                                                                                                                                                            |
| Hallucination                                                                   | Incorrect information given by Gen AI and chatbots.                                                                                                                                                                                                                                                                        |
| Hardcoded credentials                                                           | Sensitive pieces of information, such as usernames, passwords, or API keys, that are sometimes embedded directly into the source code of an application.                                                                                                                                                                   |
| Hoax                                                                            | An attack that involves the distribution of false alarms or misinformation to deceive, create panic, or manipulate individuals.                                                                                                                                                                                            |
| HTTP                                                                            | A foundational application protocol that facilitates communication between web browsers and web servers.                                                                                                                                                                                                                   |
| Impersonation                                                                   | An attack where the attacker adopts a false identity to deceive individuals or organizations into granting access to restricted areas or divulging sensitive information.                                                                                                                                                  |
| Incident response                                                               | A structured approach that promptly addresses and manages security incidents, breaches, or cyberattacks.                                                                                                                                                                                                                   |
| Ingress filtering                                                               | A type of packet filtering that establishes a critical network security measure where traffic is inspected and managed at the point of entry to the network. The primary goal of ingress filtering is to allow only authentic and legitimate traffic and block access to unauthorized or potentially harmful data packets. |
| Injection attack                                                                | A type of cybersecurity attack that involves a hacker injecting malicious code into a query, web application, or system, triggering remote commands that manipulate data on a website or modify a database.                                                                                                                |
| Input validation                                                                | A programming technique that ensures data entered into an application is correct, safe, and in the expected format before processing.                                                                                                                                                                                      |
| Insider attack                                                                  | An attack attributed to people who have authorized access to an organization's resources, personnel, system, and network.                                                                                                                                                                                                  |
| Interactive application security testing (IAST)                                 | A type of application security testing that combines static and dynamic testing principles, examining the application's code in real-time while testers interact with the live application.                                                                                                                                |
| International Monetary Fund (IMF)                                               | A policy to promote financial stability and monetary cooperation.                                                                                                                                                                                                                                                          |
| Intrusion detection and prevention system (IDPS)                                | A security solution situated just beyond the firewall that scrutinizes incoming network traffic to identify and manage potential security threats.                                                                                                                                                                         |
| Intrusion detection system (IDS)                                                | A security mechanism that identifies unusual activities and alerts security administrators or system operators for further analysis.                                                                                                                                                                                       |
| IP packet                                                                       | A fundamental unit of data exchanged over the internet or any IP-based network.                                                                                                                                                                                                                                            |
| IP spoofing                                                                     | A technique that involves manipulating packet headers to alter the source address, concealing the sender's actual origin, or pretending to be another host.                                                                                                                                                                |
| Keylogger                                                                       | A malware that records keystrokes on a computer to capture sensitive information.                                                                                                                                                                                                                                          |
| Logic bomb                                                                      | A malicious code that remains dormant until triggered by a specific event or condition.                                                                                                                                                                                                                                    |
| Malicious insider                                                               | A knowledgeable actor within an entity who exploits their access to inflict damage, steal data, or disrupt operations.                                                                                                                                                                                                     |
| Malvertising                                                                    | A malicious advertisement that contains hidden code to deliver malware to users' devices.                                                                                                                                                                                                                                  |
| Malware                                                                         | A malicious software that is specifically created with the intent to disrupt or gain unauthorized access to a system or network.                                                                                                                                                                                           |
| Man-in-the-middle attack                                                        | A type of cybersecurity attack that involves intercepting communication between two systems, modifying the packets, and then forwarding them without detection by the authentic communicator or recipient.                                                                                                                 |
| Mobile device management (MDM)                                                  | A proven methodology and toolset that provides a workforce with mobile productivity tools and applications while keeping corporate data secure.                                                                                                                                                                            |
| Mobile telecommunications networks (MTN)                                        | A telecommunications company.                                                                                                                                                                                                                                                                                              |
| Multifactor authentication (MFA)                                                | An account security measure requiring multiple verification forms before granting access to an account or a system. This security measure often combines two or more forms of verification.                                                                                                                                |
| National Cyber Security Division (NCSD)                                         | A division of the Office of Cyber Security and Communications, within the United States Department of Homeland Security's Cybersecurity and Infrastructure Security Agency.                                                                                                                                                |
| National Institute of Standards and Technology (NIST)                           | A physical science laboratory, currently part of the US Department of Commerce, renowned for establishing industry standards.                                                                                                                                                                                              |
| National Security Agency (NSA)                                                  | An agency that prevents and eradicates threats to U.S. national security systems with a focus on the Defense Industrial Base and the improvement of weapons' security.                                                                                                                                                     |
| National Security Decision Directives (NSDD) 145                                | A directive that gave the NSA control over all government computer systems containing "sensitive but unclassified" information.                                                                                                                                                                                            |
| National Telecommunications and Information Systems Security Committee (NTISSC) | A committee that provides a forum for the discussion of policy issues, sets national policy, and promulgates direction, operational procedures, and guidance for the security of national security systems through the NSTISSC issuance system.                                                                            |
| Negligent insider                                                               | An individual who ignores security protocols or bypasses policies for the sake of convenience, due to overconfidence in their knowledge, or sheer disregard for laws.                                                                                                                                                      |
| Oblivious insider                                                               | An unsuspecting employee who, due to lack of awareness or understanding, unintentionally engages in an action that exposes the organization to risk.                                                                                                                                                                       |
| Open vulnerability assessment system (OpenVAS)                                  | A free, open-source tool that provides a solid scanning solution for those who prefer a community-driven approach.                                                                                                                                                                                                         |
| Packet sniffing                                                                 | A technique that involves using software to capture and analyze data packets as they move through a network. When deployed, this software collects various data points by intercepting traffic.                                                                                                                            |
| Passive sniffing                                                                | A technique used to capture and analyze network traffic without actively sending any packets to the network.                                                                                                                                                                                                               |
| Patch                                                                           | Security updates on the software.                                                                                                                                                                                                                                                                                          |
| Patching                                                                        | The process of updating software and systems with small pieces of code, typically known as patches or updates. These patches and updates fix vulnerabilities and bugs or enhance functionality.                                                                                                                            |
| Penetration testing                                                             | A robust defense strategy, where security specialists simulate cyberattacks to find vulnerabilities before malicious actors do.                                                                                                                                                                                            |
| Phishing                                                                        | A fraudulent attempt to obtain sensitive information by masquerading as a trustworthy entity through electronic communication.                                                                                                                                                                                             |
| Physical controls                                                               | A category of security controls that secures and protects the tangible assets of an organization, such as the company's hardware, infrastructure, and environment.                                                                                                                                                         |
| Preventive controls                                                             | A category of security controls that aims to stop security incidents before they occur.                                                                                                                                                                                                                                    |
| Professional insider                                                            | An individual who has been recruited into an espionage organization.                                                                                                                                                                                                                                                       |
| Quad9                                                                           | A free capability to change the DNS in your browser settings to four 9s with a blacklist that prevents visiting bad websites.                                                                                                                                                                                              |
| Ransomware                                                                      | A malware that encrypts files on a victim's system and demands a ransom for their release.                                                                                                                                                                                                                                 |
| Retrieval augmented generation (RAG)                                            | A strategy that helps systems become more accurate.                                                                                                                                                                                                                                                                        |
| Rootkit                                                                         | A stealthy malware that is designed to gain unauthorized access and control over a computer system.                                                                                                                                                                                                                        |
| Secure logging                                                                  | The practice of recording events to track user and system activities, making it easier to understand how the software operates and identify any unusual or unauthorized activities.                                                                                                                                        |
| Secure sockets layer (SSL)                                                      | A security measure where data transmitted over the internet is encrypted using SSL certificates from trusted authorities, making it unreadable to anyone who might intercept the communication.                                                                                                                            |
| Security information and event management (SIEM)                                | A protective measure integral to enhancing network security. SIEMs aggregate and analyze log and event data from servers, endpoints, and network devices.                                                                                                                                                                  |
| Security orchestration, automation, and response (SOAR)                         | An automation solution that empowers security teams to manage alerts efficiently, often reducing the time to respond to incidents. These solutions integrate various security tools and processes, automating workflows and incident response actions.                                                                     |
| SEO poisoning                                                                   | An attack where the attacker puts up a fake website that tricks the search engine into listing it high on the search results.                                                                                                                                                                                              |
| Server cross-site scripting (XSS) attack                                        | A type of XSS attack that occurs when user data is incorporated into the server's HTTP response.                                                                                                                                                                                                                           |
| Shoulder surfing                                                                | An attack involving the direct observation of a person's private information by peering over their shoulder, a practice commonly seen when an individual is entering sensitive data, such as passwords.                                                                                                                    |
| Smishing                                                                        | An attack where SMS message phishing comes through a search engine.                                                                                                                                                                                                                                                        |
| Smurf attack                                                                    | A type of distributed denial-of-service (DDoS) attack that relies on internet control message protocol (ICMP) echo requests. These attacks typically exploit vulnerabilities in older network devices.                                                                                                                     |
| Social engineering                                                              | A malware attack that hacks humans.                                                                                                                                                                                                                                                                                        |
| Software development life cycle (SDLC)                                          | A sequence of stages outlining the software development process from the beginning to the end. The SDLC starts with planning, identifying, and analyzing requirements, then goes through design, programming, testing, deployment, and maintenance.                                                                        |
| Software security testing                                                       | A critical process designed to assess and ensure the overall security of a software application. It involves a series of evaluations to uncover vulnerabilities, flaws, or weaknesses that malicious actors could exploit.                                                                                                 |
| Spam filter                                                                     | A critical tool that shields your email inboxes from deceptive tactics.                                                                                                                                                                                                                                                    |
| Spear phishing                                                                  | A more targeted version of phishing where attackers tailor their approach to a specific individual or organization. It involves personalized emails that appear credible enough to deceive the target into sharing confidential information.                                                                               |
| SQL injection                                                                   | A type of cybersecurity attack where hackers inject malicious code into databases, manipulating SQL queries to execute unauthorized commands or gain unauthorized access to sensitive data.                                                                                                                                |
| Spyware                                                                         | A malicious software that covertly collects user information and internet behavior without their consent, often for advertising purposes.                                                                                                                                                                                  |
| Static application security testing (SAST)                                      | A type of application security testing that inspects the source code without executing the program, guiding developers to vulnerabilities and often providing targeted advice to fix the vulnerability.                                                                                                                    |
| Synchronize-acknowledge (SYN-ACK) attack                                        | A type of distributed denial-of-service (DDoS) attack where attackers inundate the target server with a large volume of SYN packets with spoofed source IP addresses.                                                                                                                                                      |
| System security                                                                 | Measures implemented to protect computer systems and their information from unauthorized access, damage, or theft.                                                                                                                                                                                                         |
| System-level firewalls                                                          | A software that runs on individual computers or servers. These firewalls operate by inspecting incoming and outgoing network packets against predefined rulesets.                                                                                                                                                          |
| Tailgating                                                                      | A physical security breach that occurs when an attacker exploits a moment when a controlled entry point is opened by an authorized individual.                                                                                                                                                                             |
| Technical controls                                                              | A category of security controls that protect information confidentiality, integrity, and availability. Technical controls detect and respond to security incidents, mitigating vulnerabilities and ensuring that only authorized individuals gain access to sensitive systems and data.                                    |
| Transmission control protocol (TCP)                                             | A fundamental protocol of internet communications. TCP offers a reliable and effective method for data transmission over networks.                                                                                                                                                                                         |
| Trojan                                                                          | A type of malware that disguises itself as legitimate software, deceiving users into executing malicious code that can lead to data theft or system harm.                                                                                                                                                                  |
| Two-factor authentication                                                       | An identity confirmation method that requires users to provide two forms of authentication, like a password and a one-time passcode (OTP), to verify their identity and access an online account or other vulnerable resources.                                                                                            |
| USA Freedom Act                                                                 | An act that was enacted in 2015 and limited the scope of surveillance by intelligence agencies.                                                                                                                                                                                                                            |
| USA PATRIOT Act                                                                 | An act uniting and strengthening America by providing appropriate tools required to intercept and obstruct terrorism.                                                                                                                                                                                                      |
| User datagram protocol (UDP)                                                    | A connectionless protocol used for transmitting data over network connections.                                                                                                                                                                                                                                             |
| Virtual private network (VPN)                                                   | A technology that encrypts your internet traffic and obscures your IP address and geographical location. You can use a VPN to reroute your internet connection through a secured server, which then interfaces with the wider internet on your behalf.                                                                     |
| Virus                                                                           | A malicious software that attaches itself to clean files and spreads through a computer system, corrupting data and hindering performance.                                                                                                                                                                                 |
| Vishing                                                                         | An attack where an attacker uses phone calls instead of emails to scam individuals.                                                                                                                                                                                                                                        |
| Vulnerability management                                                        | The process of identifying, evaluating, prioritizing, mitigating, and monitoring security vulnerabilities in computer systems, networks, and software applications.                                                                                                                                                        |
| War Operation Plan Response (WOPR)                                              | A war game programmed to continuously run military simulations and learn over time.                                                                                                                                                                                                                                        |
| Watering hole attack                                                            | An attack where cybercriminals identify and compromise websites that are popular with their intended victims.                                                                                                                                                                                                              |
| Whaling                                                                         | A form of spear phishing that specifically targets high-profile individuals like CEOs or CFOs, the "big fishes" in an organization.                                                                                                                                                                                        |
| Wireshark                                                                       | A network protocol analyzer that captures and interactively displays detailed network traffic patterns that occur as data packets traverse the network. These patterns help identify potential bottlenecks or anomalies.                                                                                                   |
| Worm                                                                            | A type of malicious software that often spreads autonomously, proliferating its destructive payload without requiring human facilitation.                                                                                                                                                                                  |
| X-Force                                                                         | A global team from IBM comprises ethical hackers, incident responders, researchers, and analysts.                                                                                                                                                                                                                          |
