# Microsoft Management Console

- MMC = UI
- Windows system management
- Enviroment customization
- Snap-ins = control system components
- Examples:
  - Device Manager
  - Disk Management
  - Services
  - Event Viewer

## Caracteristicas

- interfaz unificada(Unified interface).
- Sistema administrador centralizado(System management from a central location).
- administración centralizada de tareas(Centralize admin tasks).
