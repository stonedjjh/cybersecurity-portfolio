# Pasos en una evaluación de vulnerabilidades

1. **Identificación**: identifica las vulnerabilidades. Puedes hacerlo probando el estado de seguridad de las aplicaciones, servidores y   otros sistemas manualmente o con una herramienta automatizada de análisis de vulnerabilidades.
  También puedes identificar vulnerabilidades mediante un sistema de gestión de activos, que es un software para gestionar activos físicos, como computadoras, o activos digitales, como archivos de hojas de cálculo. Incluso puedes consultar fuentes de inteligencia de amenazas, incluidas bases de datos de vulnerabilidades y fuentes de inteligencia de amenazas.

2. **Análisis**: analizas todos los datos e inteligencia disponibles para identificar la causa principal de cada vulnerabilidad descubierta en el paso 1

3. ***Priorización***: se priorizan las vulnerabilidades, determinando cuáles abordar y en qué orden. Para determinar la prioridad, se clasifican las vulnerabilidades por gravedad mediante un sistema de clasificación o puntaje de vulnerabilidades. Por ejemplo, el sistema de clasificación puede incluir tres niveles de gravedad de vulnerabilidad: moderado, alto o crítico.

4. **Corrección**: aplicas parches, instalas controles de seguridad y realizas otras tareas para corregir vulnerabilidades conocidas. Debes abordar las vulnerabilidades por prioridad: crítica, alta y luego moderada, por ejemplo.

## Informes de Evaluaciones

Los informes de evaluación de vulnerabilidades adoptan varias formas. Por lo general, incluyen los componentes que se muestran en el ejemplo:

1. **Resumen**: una introducción que resume la evaluación.

2. **Hallazgos**: una lista descriptiva de cada vulnerabilidad ordenada de mayor a menor gravedad

3. **Recomendaciones**: una lista de controles recomendados enumerados en el mismo orden que las vulnerabilidades

4. **Conclusión**: Una conclusión que resume los hallazgos y recomendaciones
