# Glosario Unificado de Ciberseguridad

| Término                                                                                                              | Definición                                                                                                                                                                                                                      |
| :------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Acceso control (Access control)**                                                                                  | Una característica de seguridad que restringe y regula quién puede ver o usar recursos en un sistema informático.                                                                                                               |
| **Acción Correctiva (Corrective controls)**                                                                          | Una categoría de controles de seguridad implementados para abordar las consecuencias de una violación de seguridad. Estos controles incorporan estrategias para mitigar los impactos de un incidente y prevenir su recurrencia. |
| **Adware**                                                                                                           | Software malicioso que muestra publicidad no deseada en el dispositivo de un usuario.                                                                                                                                           |
| **Agencia de Ciberseguridad y Seguridad de la Infraestructura (CISA)**                                               | Una agencia de Estados Unidos responsable de la ciberseguridad y de la protección de infraestructuras en todos los niveles de gobierno.                                                                                         |
| **Agencia de Seguridad Nacional (NSA)**                                                                              | Una agencia que previene y erradica amenazas a los sistemas de seguridad nacional de EE. UU., con enfoque en la Base Industrial de Defensa y en la mejora de la seguridad de los armamentos.                                    |
| **Análisis de Seguridad de Aplicaciones Dinámicas (DAST)**                                                           | Un tipo de prueba de seguridad que implica ejecutar código durante la evaluación y probar todas las interfaces orientadas al usuario con diversas entradas para encontrar posibles problemas de seguridad.                      |
| **Análisis de Seguridad de Aplicaciones Estáticas (SAST)**                                                           | Un tipo de prueba de seguridad de aplicaciones que inspecciona el código fuente sin ejecutar el programa, guiando a los desarrolladores hacia vulnerabilidades y a menudo proporcionando consejos específicos para corregirlas. |
| **Análisis de Seguridad de Aplicaciones Interactivo (IAST)**                                                         | Un tipo de prueba de seguridad de aplicaciones que combina principios de prueba estática y dinámica, examinando el código de la aplicación en tiempo real mientras los evaluadores interactúan con la aplicación en vivo.       |
| **Análisis Forense Digital (Digital forensics)**                                                                     | Una rama de la ciencia forense que proporciona las herramientas y técnicas requeridas para recolectar y analizar evidencia digital, ayudando a comprender la naturaleza del incidente y sus implicaciones.                      |
| **Antivirus (Antivirus software)**                                                                                   | Una herramienta crítica para la seguridad del sistema que sirve como primera línea de defensa contra virus y malware.                                                                                                           |
| **Ataque de Inyección (Injection attack)**                                                                           | Un tipo de ataque de ciberseguridad que involucra a un _hacker_ inyectando código malicioso en una consulta, aplicación web o sistema, provocando comandos remotos que manipulan datos o modifican una base de datos.           |
| **Ataque de Inyección SQL (SQL injection)**                                                                          | Un tipo de ataque de ciberseguridad donde _hackers_ inyectan código malicioso en bases de datos, manipulando consultas SQL para ejecutar comandos no autorizados o ganar acceso no autorizado a datos sensibles.                |
| **Ataque de Rastreo Activo (Active sniffing)**                                                                       | Una técnica utilizada en seguridad de redes para interceptar y examinar activamente paquetes de datos que viajan a través de una red.                                                                                           |
| **Ataque de Rastreo Pasivo (Passive sniffing)**                                                                      | Una técnica utilizada para capturar y analizar tráfico de red sin enviar activamente ningún paquete a la red.                                                                                                                   |
| **Ataque de Suplantación (Impersonation)**                                                                           | Un ataque donde el atacante adopta una identidad falsa para engañar a individuos u organizaciones y obtener acceso a áreas restringidas o divulgar información sensible.                                                        |
| **Ataque de 'watering hole'**                                                                                        | Un ataque donde los cibercriminales identifican y comprometen sitios web que son populares entre sus víctimas previstas.                                                                                                        |
| **Ataque de 'whaling'**                                                                                              | Una forma de _spear phishing_ que se dirige específicamente a individuos de alto perfil como CEOs o CFOs, los "peces gordos" en una organización.                                                                               |
| **Ataque Interno (Insider attack)**                                                                                  | Un ataque atribuido a personas que tienen acceso autorizado a los recursos, personal, sistemas y red de una organización.                                                                                                       |
| **Ataque Man-in-the-Middle (Man-in-the-middle attack)**                                                              | Un tipo de ataque de ciberseguridad que involucra interceptar la comunicación entre dos sistemas, modificar los paquetes y luego reenviarlos sin detección.                                                                     |
| **Ataque SYN-ACK (Synchronize-acknowledge (SYN-ACK) attack)**                                                        | Un tipo de Denegación de Servicio Distribuido (DDoS) donde atacantes inundan el servidor objetivo con un gran volumen de paquetes SYN con direcciones IP de origen falsificadas.                                                |
| **Ataque Smurf (Smurf attack)**                                                                                      | Un tipo de Denegación de Servicio Distribuido (DDoS) que se basa en solicitudes de eco de Protocolo de Mensajes de Control de Internet (ICMP). Estos ataques suelen explotar vulnerabilidades en dispositivos de red antiguos.  |
| **Ataque XSS (Cross-site scripting (XSS) attack)**                                                                   | Una brecha de seguridad donde atacantes incrustan _scripts_ dañinos en páginas web que suelen considerarse seguras.                                                                                                             |
| **Ataque XSS del Servidor (Server cross-site scripting (XSS) attack)**                                               | Un tipo de ataque XSS que ocurre cuando los datos del usuario se incorporan a la respuesta HTTP del servidor.                                                                                                                   |
| **Autenticación Multifactor (MFA/Multifactor authentication)**                                                       | Una medida de seguridad de cuenta que requiere múltiples formas de verificación antes de otorgar acceso a una cuenta o sistema.                                                                                                 |
| **Autenticación de Dos Factores (Two-factor authentication)**                                                        | Un método de confirmación de identidad que requiere que los usuarios proporcionen dos formas de autenticación (como contraseña y código) para verificar su identidad y acceder a un recurso.                                    |
| **Bot**                                                                                                              | Software automatizado que realiza tareas maliciosas en internet. Funciona junto a otras computadoras infectadas para crear una _botnet_.                                                                                        |
| **Botnet**                                                                                                           | Una colección de computadoras interconectadas controladas centralmente por uno o más atacantes. Cada computadora comprometida ejecuta un programa _bot_ especializado.                                                          |
| **Bring-your-own-device (BYOD)**                                                                                     | Una política empresarial que permite a los empleados usar dispositivos personales para tareas relacionadas con el trabajo.                                                                                                      |
| **Bulo (Hoax)**                                                                                                      | Un ataque que implica la distribución de falsas alarmas o desinformación para engañar, crear pánico o manipular a individuos.                                                                                                   |
| **Caballo de Troya (Trojan)**                                                                                        | Un tipo de _malware_ que se disfraza como software legítimo, engañando a los usuarios para que ejecuten código malicioso.                                                                                                       |
| **Cadena de Custodia (Chain of custody)**                                                                            | Un rastro documentado que proporciona un registro claro de quién accedió a la evidencia, cuándo y qué acciones se tomaron.                                                                                                      |
| **Ciberactivista (Hacktivist)**                                                                                      | Un actor de amenaza motivado por agendas políticas o sociales.                                                                                                                                                                  |
| **CIA Triad**                                                                                                        | Un concepto fundamental en ciberseguridad que representa tres principios básicos: Confidencialidad, Integridad y Disponibilidad.                                                                                                |
| **Cifrado (Encryption)**                                                                                             | El proceso de convertir información en código, haciendo que el contenido original sea ilegible sin la clave de descifrado.                                                                                                      |
| **Cifrado de Disco Completo (Full-disk encryption)**                                                                 | Una técnica de seguridad que cifra cada archivo y dato en la unidad, haciendo que el contenido de todo el disco sea inaccesible sin la contraseña o clave de descifrado.                                                        |
| **Ciclo de Vida de Desarrollo de Software (SDLC/Software development life cycle)**                                   | Una secuencia de etapas que describe el proceso de desarrollo de software desde el principio hasta el final.                                                                                                                    |
| **Comité de Seguridad de Sistemas Nacionales de Telecomunicaciones e Información (NTISSC)**                          | Un comité que ofrece un foro para la discusión de políticas y promulga directrices para la seguridad de los sistemas de seguridad nacional.                                                                                     |
| **Contención (Containment)**                                                                                         | Un conjunto de acciones tomadas para limitar el daño causado por un incidente, como aislar sistemas afectados o sacarlos temporalmente de línea.                                                                                |
| **Control de Acceso a la Red (NAC/Network access control)**                                                          | Un "guardián" de la seguridad de la red que gestiona la autenticación y autorización del usuario para controlar la entrada y las actividades de la red.                                                                         |
| **Control de Dispositivos Móviles (MDM/Mobile device management)**                                                   | Una metodología y conjunto de herramientas probados que proporcionan productividad móvil manteniendo los datos corporativos seguros.                                                                                            |
| **Controles Administrativos (Administrative controls)**                                                              | Una categoría de controles de seguridad que establece directrices y metodologías para garantizar que los empleados se adhieran a los protocolos de seguridad.                                                                   |
| **Controles Detectivos (Detective controls)**                                                                        | Una categoría de controles de seguridad que juega un papel crítico en la identificación y alerta de cualquier acción incorrecta o no autorizada.                                                                                |
| **Controles Disuasorios (Deterrent controls)**                                                                       | Una categoría de controles de seguridad que desalienta las desviaciones de los procedimientos de seguridad y disminuye la probabilidad de ataques intencionales.                                                                |
| **Controles Físicos (Physical controls)**                                                                            | Una categoría de controles de seguridad que asegura y protege los activos tangibles de una organización, como hardware, infraestructura y entorno.                                                                              |
| **Controles Preventivos (Preventive controls)**                                                                      | Una categoría de controles de seguridad que tiene como objetivo detener los incidentes de seguridad antes de que ocurran.                                                                                                       |
| **Controles Técnicos (Technical controls)**                                                                          | Una categoría de controles de seguridad que protege la confidencialidad, integridad y disponibilidad, mitigando vulnerabilidades y asegurando el acceso autorizado.                                                             |
| **Copia de pantalla (Shoulder surfing)**                                                                             | Un ataque que consiste en la observación directa de la información privada de una persona mirando por encima de su hombro.                                                                                                      |
| **Credenciales Hardcodeadas (Hardcoded credentials)**                                                                | Piezas de información sensible (como contraseñas) que a veces se incrustan directamente en el código fuente de una aplicación.                                                                                                  |
| **Deep fakes**                                                                                                       | Tecnología que simula la voz, imagen y apariencia de un individuo.                                                                                                                                                              |
| **Defensa en Profundidad (Defense in depth)**                                                                        | Un enfoque integral que implica implementar múltiples capas de seguridad en toda la infraestructura de TI de una organización.                                                                                                  |
| **Denegación de Servicio Distribuida (DDoS/Distributed denial-of-service)**                                          | Un intento malicioso de interrumpir el funcionamiento rutinario de un servidor, servicio o red al inundarlo con tráfico de múltiples fuentes.                                                                                   |
| **Departamento de Seguridad Nacional (DHS)**                                                                         | Un departamento encargado de proteger la nación contra amenazas físicas y cibernéticas.                                                                                                                                         |
| **Directiva de Decisión de Seguridad Nacional (NSDD) 145**                                                           | Una directiva que otorgó a la NSA control sobre todos los sistemas informáticos gubernamentales que contienen información "sensible pero no clasificada".                                                                       |
| **División Nacional de Ciberseguridad (NCSD)**                                                                       | Una división dentro del Departamento de Seguridad Nacional de Estados Unidos.                                                                                                                                                   |
| **DNS (Domain Name Server)**                                                                                         | Un "directorio telefónico" de internet que traduce nombres de dominio a direcciones IP.                                                                                                                                         |
| **Document Object Model (DOM)**                                                                                      | Una interfaz basada en objetos que crea un documento XML como una estructura similar a un árbol en la memoria del navegador.                                                                                                    |
| **Dumpster diving**                                                                                                  | Un ataque que implica buscar entre los elementos desechados de un individuo o empresa en busca de datos valiosos.                                                                                                               |
| **Egreso de Filtrado (Egress filtering)**                                                                            | Una técnica utilizada para proteger su red de la falsificación de IP, examinando los paquetes IP salientes.                                                                                                                     |
| **Endpoint Security**                                                                                                | La práctica de asegurar _endpoints_ (computadoras, móviles, servidores) dentro de una red de ataques cibernéticos.                                                                                                              |
| **Error (Hallucination)**                                                                                            | Información incorrecta proporcionada por la IA generativa y los chatbots.                                                                                                                                                       |
| **Fallo de Manejo de Errores (Error handling)**                                                                      | El proceso de responder y gestionar errores que surgen durante la operación o ejecución de aplicaciones.                                                                                                                        |
| **Falsificación de DNS (Domain name system (DNS) falsification)**                                                    | Un ciberataque donde atacantes corrompen o alteran los registros DNS para redirigir a los usuarios a sitios web maliciosos.                                                                                                     |
| **Filtro de spam (Spam filter)**                                                                                     | Una herramienta crítica que protege las bandejas de entrada de correo electrónico de tácticas engañosas.                                                                                                                        |
| **Firewalls**                                                                                                        | Una barrera de hardware o software que filtra e impide que el tráfico de datos no autorizado o malicioso entre o salga de una red.                                                                                              |
| **Fondo Monetario Internacional (IMF)**                                                                              | Una política destinada a promover la estabilidad financiera y la cooperación monetaria.                                                                                                                                         |
| **Fuerza de Tarea Avanzada y Persistente (APT/Advanced persistent threat)**                                          | Un ciberataque sofisticado donde los atacantes se mueven lateralmente en la red, sin ser detectados.                                                                                                                            |
| **Generación Aumentada por Recuperación (RAG)**                                                                      | Una estrategia que ayuda a los sistemas a ser más precisos.                                                                                                                                                                     |
| **Gusano (Worm)**                                                                                                    | Un tipo de software malicioso que a menudo se propaga de forma autónoma.                                                                                                                                                        |
| **HTTP**                                                                                                             | Un protocolo de aplicación fundamental que facilita la comunicación entre navegadores web y servidores web.                                                                                                                     |
| **Incident Response (Respuesta a Incidentes)**                                                                       | Un enfoque estructurado que aborda y gestiona con prontitud incidentes de seguridad, brechas o ciberataques.                                                                                                                    |
| **Ingeniería social (Social engineering)**                                                                           | Un ataque de _malware_ que se dirige a humanos (manipulación psicológica).                                                                                                                                                      |
| **Ingreso de Filtrado (Ingress filtering)**                                                                          | Un tipo de filtrado de paquetes que inspecciona y gestiona el tráfico en el punto de entrada a la red para bloquear accesos no autorizados.                                                                                     |
| **Insider despistado (Oblivious insider)**                                                                           | Un empleado desprevenido que, por falta de concienciación o comprensión, realiza involuntariamente una acción que expone a la organización a riesgos.                                                                           |
| **Insider malicioso (Malicious insider)**                                                                            | Un actor con conocimiento dentro de una entidad que explota su acceso para infligir daño, robar datos o interrumpir operaciones.                                                                                                |
| **Insider negligente (Negligent insider)**                                                                           | Un individuo que ignora los protocolos de seguridad o evade políticas por conveniencia.                                                                                                                                         |
| **Insider profesional (Professional insider)**                                                                       | Un individuo que ha sido reclutado por una organización de espionaje.                                                                                                                                                           |
| **Instituto Nacional de Estándares y Tecnología (NIST)**                                                             | Un laboratorio de ciencia física conocido por establecer estándares de la industria.                                                                                                                                            |
| **Intrusión con Inyección de SQL (SQL injection)**                                                                   | Un tipo de ataque de ciberseguridad donde _hackers_ inyectan código malicioso en bases de datos.                                                                                                                                |
| **Intrusión con _Packet Sniffing_ (Packet sniffing)**                                                                | Una técnica que implica usar software para capturar y analizar paquetes de datos a medida que se mueven a través de una red.                                                                                                    |
| **IP Packet**                                                                                                        | Una unidad fundamental de datos intercambiada a través de internet o cualquier red basada en IP.                                                                                                                                |
| **IP Spoofing (Suplantación de IP)**                                                                                 | Una técnica que involucra manipular encabezados de paquetes para alterar la dirección de origen, ocultando el origen real del remitente.                                                                                        |
| **Keylogger**                                                                                                        | Un _malware_ que registra las pulsaciones de teclado en una computadora para capturar información sensible.                                                                                                                     |
| **Ley de Libertad de EE. UU. (USA Freedom Act)**                                                                     | Una ley promulgada en 2015 que limitó el alcance de la vigilancia por parte de las agencias de inteligencia.                                                                                                                    |
| **Ley PATRIOT de EE. UU. (USA PATRIOT Act)**                                                                         | Una ley destinada a unir y fortalecer a Estados Unidos proporcionando las herramientas apropiadas para interceptar y obstaculizar el terrorismo.                                                                                |
| **Lógica Bomba (Logic bomb)**                                                                                        | Código malicioso que permanece inactivo hasta que es activado por un evento o condición específico.                                                                                                                             |
| **Malware**                                                                                                          | Software malicioso creado específicamente con la intención de interrumpir u obtener acceso no autorizado a un sistema o red.                                                                                                    |
| **Malware sin Archivo (Fileless malware)**                                                                           | Una forma de software malicioso que opera dentro de la memoria de la computadora sin dejar rastros en el sistema de archivos.                                                                                                   |
| **Malvertising**                                                                                                     | Publicidad maliciosa que contiene código oculto para entregar _malware_ a los dispositivos de los usuarios.                                                                                                                     |
| **Manejo de Dispositivos Móviles (MDM/Mobile device management)**                                                    | Una metodología y conjunto de herramientas probados que proporcionan productividad móvil manteniendo los datos corporativos seguros.                                                                                            |
| **Mapeo de Redes (Network mapping)**                                                                                 | El proceso de comprender y visualizar las conexiones físicas y lógicas de una red.                                                                                                                                              |
| **Medidas de Seguridad de Sistema (System security)**                                                                | Medidas implementadas para proteger los sistemas informáticos y su información del acceso no autorizado, daño o robo.                                                                                                           |
| **Modelo de pensamiento crítico**                                                                                    | Un modelo que comprende cinco elementos: características del pensamiento, habilidades técnicas, habilidades interpersonales, conocimientos teóricos y experimentales, y capacidades intelectuales.                              |
| **Multifactor authentication (MFA)**                                                                                 | Una medida de seguridad de cuenta que requiere múltiples formas de verificación antes de otorgar acceso.                                                                                                                        |
| **National Cyber Security Division (NCSD)**                                                                          | Una división dentro del Departamento de Seguridad Nacional de Estados Unidos.                                                                                                                                                   |
| **Network Interface Card (NIC)**                                                                                     | Un adaptador de red que solo presta atención al tráfico dirigido a ella; en modo promiscuo, captura todo el tráfico de la red.                                                                                                  |
| **Network Mapper (Nmap)**                                                                                            | Una herramienta de mapeo de red que permite a los administradores identificar dispositivos, descubrir puertos abiertos y detectar riesgos de seguridad.                                                                         |
| **Open Vulnerability Assessment System (OpenVAS)**                                                                   | Una herramienta gratuita y de código abierto que proporciona una solución de escaneo sólida.                                                                                                                                    |
| **Parche (Patch)**                                                                                                   | Actualizaciones de seguridad en el software.                                                                                                                                                                                    |
| **Parcheo (Patching)**                                                                                               | El proceso de actualizar software y sistemas con pequeños códigos conocidos como parches para corregir vulnerabilidades y errores.                                                                                              |
| **Pensamiento crítico**                                                                                              | La capacidad de analizar objetivamente la información y formar juicios razonados.                                                                                                                                               |
| **Phishing**                                                                                                         | Intento fraudulento de obtener información sensible haciéndose pasar por una entidad de confianza.                                                                                                                              |
| **Phishing dirigido (Spear phishing)**                                                                               | Versión más dirigida del _phishing_ donde los atacantes adaptan su enfoque a un individuo u organización específicos.                                                                                                           |
| **Phishing general**                                                                                                 | Un ataque de _phishing_ donde los atacantes envían correos electrónicos a un grupo masivo.                                                                                                                                      |
| **Phishing por SMS (Smishing)**                                                                                      | Un ataque de _phishing_ por mensaje de texto.                                                                                                                                                                                   |
| **Phishing por Voz (Vishing)**                                                                                       | Un ataque donde un atacante utiliza llamadas telefónicas en lugar de correos electrónicos para estafar.                                                                                                                         |
| **Prueba de Penetración (Penetration testing)**                                                                      | Una sólida estrategia de defensa donde especialistas en seguridad simulan ciberataques para encontrar vulnerabilidades.                                                                                                         |
| **Protocolo de Control de Transmisión (TCP/Transmission control protocol)**                                          | Un protocolo fundamental de las comunicaciones por internet que ofrece un método fiable y eficaz para la transmisión de datos.                                                                                                  |
| **Protocolo de Datagramas de Usuario (UDP/User datagram protocol)**                                                  | Un protocolo sin conexión utilizado para la transmisión de datos.                                                                                                                                                               |
| **Protocolo de Resolución de Direcciones (ARP/Address resolution protocol)**                                         | Un protocolo de red utilizado para mapear una dirección IP a una dirección MAC dentro de una red local.                                                                                                                         |
| **Quad9**                                                                                                            | Una capacidad gratuita para cambiar el DNS en la configuración de su navegador a cuatro 9s con una lista negra.                                                                                                                 |
| **Ransomware**                                                                                                       | Un _malware_ que cifra archivos en el sistema de una víctima y exige un rescate por su liberación.                                                                                                                              |
| **Recuperación (Backup)**                                                                                            | La tarea de crear copias de datos de un sistema para que puedan ser restaurados en caso de pérdida de datos.                                                                                                                    |
| **Red de la Agencia de Proyectos de Investigación Avanzada (ARPANET)**                                               | La primera red de área amplia con conmutación de paquetes y control distribuido, e implementadora del TCP/IP.                                                                                                                   |
| **Redes de Telecomunicaciones Móviles (MTN)**                                                                        | Una empresa de telecomunicaciones.                                                                                                                                                                                              |
| **Red Privada Virtual (VPN/Virtual private network)**                                                                | Una tecnología que cifra su tráfico de internet y oculta su dirección IP y ubicación geográfica.                                                                                                                                |
| **Reglamento General de Protección de Datos (GDPR)**                                                                 | Un reglamento que enumera los derechos del titular de los datos.                                                                                                                                                                |
| **Registro Seguro (Secure logging)**                                                                                 | La práctica de registrar eventos para rastrear la actividad del usuario y del sistema e identificar actividades inusuales.                                                                                                      |
| **Rootkit**                                                                                                          | _Malware_ sigiloso diseñado para obtener acceso no autorizado y control sobre un sistema informático.                                                                                                                           |
| **Secure Sockets Layer (SSL)**                                                                                       | Una medida de seguridad donde los datos transmitidos por internet se cifran mediante certificados SSL.                                                                                                                          |
| **Seguridad de Red (Network security)**                                                                              | Una medida de protección que salvaguarda la infraestructura de red del acceso no autorizado, explotación o robo.                                                                                                                |
| **Seguridad de Software (Software security testing)**                                                                | Un proceso crítico diseñado para evaluar y garantizar la seguridad general de una aplicación de software.                                                                                                                       |
| **Segmentación de Red (Network segmentation)**                                                                       | Una táctica que divide una red en múltiples segmentos o subredes más pequeñas.                                                                                                                                                  |
| **SEO Poisoning**                                                                                                    | Un ataque donde el atacante crea un sitio web falso que engaña al motor de búsqueda para que lo liste en una posición alta.                                                                                                     |
| **Sistema de Detección de Intrusiones (IDS/Intrusion detection system)**                                             | Un mecanismo de seguridad que identifica actividades inusuales y alerta a los administradores de seguridad para su análisis.                                                                                                    |
| **Sistema de Detección y Prevención de Intrusiones (IDPS/Intrusion detection and prevention system)**                | Una solución de seguridad situada justo después del firewall que examina el tráfico de red entrante.                                                                                                                            |
| **Sistema de Gestión de Información y Eventos de Seguridad (SIEM/Security information and event management)**        | Una medida de protección integral que agrega y analiza datos de _logs_ y eventos de servidores, _endpoints_ y dispositivos de red.                                                                                              |
| **Sistema de Recuperación y Automatización de la Seguridad (SOAR/Security orchestration, automation, and response)** | Una solución de automatización que permite a los equipos de seguridad gestionar alertas de manera eficiente.                                                                                                                    |
| **Software Antivirus de Nivel de Sistema (System-level firewalls)**                                                  | Un software que se ejecuta en computadoras o servidores individuales, inspeccionando los paquetes de red contra reglas predefinidas.                                                                                            |
| **Software espía (Spyware)**                                                                                         | Software malicioso que recopila de forma encubierta información del usuario y comportamiento en internet sin su consentimiento.                                                                                                 |
| **Tailgating**                                                                                                       | Un fallo de seguridad física que ocurre cuando un atacante aprovecha un momento en que un punto de entrada controlado es abierto por un individuo autorizado.                                                                   |
| **Tribunal de Vigilancia de Inteligencia Extranjera (FISC)**                                                         | Un tribunal que atiende solicitudes de vigilancia electrónica y registros físicos con fines de inteligencia extranjera.                                                                                                         |
| **Validación de Entradas (Input validation)**                                                                        | Una técnica de programación que garantiza que los datos ingresados en una aplicación sean correctos, seguros y tengan el formato esperado.                                                                                      |
| **Virus**                                                                                                            | Software malicioso que se adhiere a archivos limpios y se propaga, corrompiendo datos y obstaculizando el rendimiento.                                                                                                          |
| **Vulnerabilidad de Gestión (Vulnerability management)**                                                             | El proceso de identificar, evaluar, priorizar, mitigar y monitorear las vulnerabilidades de seguridad en sistemas informáticos, redes y aplicaciones.                                                                           |
| **War Operation Plan Response (WOPR)**                                                                               | Un "war game" programado para ejecutar continuamente simulaciones militares y aprender con el tiempo.                                                                                                                           |
| **Wireshark**                                                                                                        | Un analizador de protocolos de red que captura y muestra interactivamente patrones detallados de tráfico de red.                                                                                                                |
| **X-Force**                                                                                                          | Un equipo global de IBM compuesto por _hackers_ éticos, respondedores de incidentes, investigadores y analistas.                                                                                                                |
